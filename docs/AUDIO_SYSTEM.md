# BGM・自然音（Phase 4B-2／4B-1,2 Update）

静かな湖の操作と釣りに集中できる、控えめな仮音源です。初期設定はOFFです。
「≡」→「サウンド設定」で **BGM・自然音** をONにし、0〜100%の整数で音量を調整します（初期音量40%）。
アタリ通知音は別系統で、環境音OFF／音量0でも従来どおりです。
メニュー内では環境音を一時停止し、閉じると現在の共有時計に従って再開します。
画面には現在の環境・停止／開始待ち／再生拒否／中断・設定保存の結果を表示します。

## 時計とミックス

| モード | 音源 | 判定 |
| --- | --- | --- |
| DAY | 穏やかな中低音の短いフレーズと柔らかな和音 | 共有時計の昼 |
| NIGHT_CLEAR | 低い音域、少ない発音と余白のある別フレーズ | 霧のない夜 |
| NIGHT_FOG | CLEARと同じ夜BGMを全量維持（補助自然音なし） | 通常霧FOG（30〜70%） |
| NIGHT_DENSE_FOG | 風、水の揺れ、遠い鳥の声を参考にした控えめな合成自然音 | 濃霧DENSE_FOG（95%） |

`src/audio/audio-mix.js`の`sampleAudioMix(gameClock.state, target?)`はWeb Audio・DOMに依存しない絶対値計算です。
既存の`createGameClock()`（昼180秒、夜180秒）だけを参照します。夜霧の判定を複製しません。
`sampleNightFog()`がDENSE_FOGの場合だけ、`intensity`を自然音の比率にし、BGMへ`1 - intensity`を掛けます。
濃霧の前後12秒は描画と同じsmoothstepです。最大時はBGMが0、自然音だけになります。
通常のFOGは実効霧量やフェードにかかわらずCLEARと同じ夜BGMを維持します。
霧量0.95そのものを音量比にしないため、濃霧ピークでBGMが5%残ることはありません。
昼夜BGMは境界の前後8秒ずつでsmoothstepクロスフェードし、180／360秒で音量が飛びません。
モード名は共有時計の昼夜判定に従い、境界付近は両方のBGMが混ざります。
再読み込みでは保存された時計を最初から参照し、別タイマーや壁時計の経過分を使いません。

## 責務と音源の交換

| ファイル | 責務 |
| --- | --- |
| `src/audio/audio-mix.js` | 時計と霧からモード・3音源の目標比率を計算 |
| `src/audio/audio-session.js` | ユーザー操作による共有AudioContextの初回生成・resume・状態通知・close |
| `src/audio/generated-sources.js` | 音源生成factory。将来OGG／MP3等をデコードしたAudioBufferへ交換する境界 |
| `src/audio/ambient-player.js` | ループ音源管理、独立gain、80msの開始／停止・音量変更、解放 |
| `src/audio/ambient-audio.js` | 設定、停止理由の合成、再生状態、純粋ミックスとplayerの接続 |
| `src/audio/audio-preferences.js` | 小規模なユーザー設定専用の厳格検証・読み書き |
| `src/ui/sound-settings.js` | DOM操作と状態表示。音声エラーをゲームの保存状態へ流さない |
| `src/ui/fishing-audio.js` | 従来のアタリ音。環境音masterを通さない独立gain |
| `src/main.js` | 共有時計、ユーザー入力、メニュー、ページのライフサイクルを接続 |

各音源は24秒・mono・22,050Hzの固定PCMループです。昼夜は正弦波と弱い倍音、滑らかな音符エンベロープ、
自然音は固定seedの帯域を抑えたノイズ、緩い振幅変化と短い丸い音を合成します。
継ぎ目も連続させます。強い打楽器、ホラー旋律、驚かせる音は追加しません。
コード内の音列・合成式をこのプロジェクト用に作成し、既存曲・録音・外部サービス・不明なライセンスの素材を使用していません。
生成コードと出力は本リポジトリのライセンス方針に従います。第三者素材を導入する場合は別途出典と利用条件を記録してください。

生成は再生が必要になった時だけで、3本合計約6.1MiBのPCMをキャッシュします。
1つのbank（ループsource 3個、channel gain 3個、master gain 1個）だけを管理します。
通常更新でノードやPCMを生成せず、異なる目標値へだけgainを滑らかに動かします。
環境音masterは最大0.3倍、音源peakも抑えており、既存アタリ音のpeak 0.12を保ちます。
数値上の差は聴感上の聞き取りやすさの保証ではありません。
停止は80msフェードの後にsourceをstop／disconnectし、参照を解除します。
停止直後の再開は解放タイマーを取り消して同じbankを使い、連打で音源を蓄積しません。
通常のメニュー停止ではPCMを再利用し、OFFではフェード後にPCMも解放します。
中断状態や最終disposeでは即時解放し、WebGL停止では共有contextも閉じます。

sourceはループ再生を担うだけで、過去の音符を予約するスケジューラーを持ちません。
開始時は現在のゲーム経過秒をループ長で割った位置を使います。
低fps・複数周期ジャンプは現在のミックスへ直接追従し、過去の音をまとめて鳴らしません。
AudioContextの時刻は発音とgainのフェードにだけ使用し、ゲーム環境の判定には使用しません。
アタリ音の発生条件・呼び出し位置は維持し、880→1320Hz・peak 0.12・0.32秒の通知を保ちます。
生成・再生の失敗は捕捉し、アワセや釣りの状態機械へ例外を伝播させません。

## 保存

音声設定はゲーム進行とは別の小規模なユーザー設定です。
専用キー`barb.audio.preferences.v1`へ次の3フィールドだけを保存します。

```json
{ "version": 1, "enabled": false, "volume": 40 }
```

バージョンは数値1、enabledはboolean、volumeは0〜100の整数のみを許可し、未知フィールドも拒否します。
入力長は256 UTF-16コード単位以内です。JSON破損・不正値・読み込み不能ではOFF／40%を採用します。
読み込みは書き込み・削除・修復をせず、明示的に設定値を変更した時だけ専用キーへ書き込みます。
書き込み失敗でも今回の設定で続け、音声設定の保存失敗を個別に表示します。次の変更で再試行できます。

ゲームの`saveVersion: 1`、`settings: {}`、2スロットの形式・世代・競合検出・保護・自動保存は変更しません。
音声設定をスロットへ混入させず、設定変更でゲームの保存成功や競合停止を発生させません。
他タブの音声設定を実行中セッションへ自動適用せず、再読み込み時に採用します。
ゲームの保存停止中も音声設定だけは独立して変更できます。

## 自動再生制限とライフサイクル

保存されたONでも、ページ読み込みだけではAudioContextを作成しません。
実際のpointerdown／keydown、ONボタン、再試行ボタンのイベント内で生成・`resume()`を呼びます。
初回操作はアタリ音も従来どおりアンロックし、環境音はONの場合だけ開始します。
非対応・生成失敗・resume拒否では無音で続行できます。

メニュー、非表示、フォーカス喪失、pagehideはそれぞれ独立した停止理由です。
全理由が解除されて初めて、現在の設定・共有時計で再開します。ページ復帰時の過去音の追い掛け再生はありません。
ロック・着信・アプリ切替等でcontextがsuspended／interruptedになった場合は音源を解放します。
focus／pageshowだけでは`resume()`せず、次のユーザー操作または「音声の開始を再試行」で再開します。
WebGL context喪失時は環境音と共有contextを解放し、既存の再読み込み案内に従います。
ブラウザが復帰を許可しない場合もゲームへ例外を流しません。

## 検証・聴取手順

```bash
npm ci
npm test
npm run build
npm run test:e2e
node scripts/render-audio-preview.mjs /tmp/barb-audio-preview
```

最後のコマンドは4モードと夕暮れ・濃霧の開始・濃霧明けのWAV（各24秒）を生成します。
音源生成と純粋ミックスを用い、初期音量40%を適用しており、音量の正規化はしていません。
AudioParamの80ms追従やブラウザ／端末の出力特性までは再現しません。
生成物はコミットしません。実際のブラウザの確認には`npm run dev`を使います。

1. 小さな端末音量から開始し、メニューでON、音量40%を選んで閉じます。
2. 昼の短いループ、3分以降の夜の低いフレーズ、境界の切り替えを聴きます。
3. 通常霧では夜BGMが維持されること、濃霧の前後12秒では自然音への移行とBGMへの復帰を確認します。
4. 再現可能な比較は生成WAVの`day`／`night-clear`／`night-fog`／`night-dense-fog`、`sunset`／`dense-fog-arrives`／`dense-fog-clears-at-dawn`を聴きます。
5. 最大100%でもアタリ通知を聞き分けられるか、ループ継ぎ目・ON/OFF・音量変更にクリックがないか確認します。
6. メニュー開閉、別タブ、画面ロック、着信・アプリ切替後の中断表示とタップ再開を確認します。

単体テストは境界、霧の強度、30/60/144fps、ジャンプ、厳格な設定検証、ストレージ障害、
ゲームセーブv1の往復互換、初回アンロック、拒否・中断、合成停止理由、発音の上限と解放、
アタリ音の音程・エンベロープ、PCMの有限値・peak・継ぎ目を検証します。
Playwrightは本番ビルドへテスト専用Web Audio観測を注入し、マウス／小型タッチ縦横、
メニュー・blur・hidden・pagehide・WebGL喪失、復元、拒否・中断、専用保存失敗を確認します。
別テストで実際のChromium AudioContextのアンロックとループ開始も実行します。
本番コードにはデバッグAPIや状態変更フックを公開しません。

自動テストやWAV生成は聴感品質の確認ではありません。実際の聴取評価、スマートフォン実機、
iOS Safari／WebKit、電話着信・画面ロックの実機確認は未実施です。
