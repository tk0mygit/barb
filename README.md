# BARB

水の上に、余白を。自然の湖を船で巡る、3D Web釣りゲームの初期プロジェクトです。

Vite + Three.js + JavaScript（ES Modules）で構築しています。湖岸、森林、背景の山、
空と波のある水面を描画し、船の操縦と、一人称視点での釣りを楽しめます。
グラフィックはすべてコードから生成しており、有料素材や外部画像・フォントは使用していません。

## 開発

Node.js 24 LTS推奨（22.12以上）、npm、WebGL 2対応のブラウザが必要です。

```sh
npm ci
npm run dev
```

開発サーバーの `/barb/` を開いてください。

```sh
npm test              # 操船・カメラ・釣り状態・ジェスチャーの単体テスト
npm run build         # dist/ に本番ビルド
npm run preview       # 本番ビルドのローカル確認
npx playwright install chromium
npm run test:e2e       # ビルド後にPC・モバイル操作を確認
```

既存のChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` に実行ファイルのパスを指定できます。
Linuxでブラウザのシステム依存が不足する場合は `npx playwright install --with-deps chromium` を実行してください。

## 操作

- **操船**：湖の画面をマウスまたは指でドラッグ。ドラッグ距離で加速、左右の移動で旋回します。
- **停船**：マウス・指を離すと徐々に減速します。
- **キーボード**：湖の画面を選択して、↑ / Wで加速、← → / A Dで旋回できます。
- **推奨釣りポイント**：水面の薄いリングが3か所の目印です。近づくと名前を表示し、船が中心から20m以内ならアタリ発生率が1.5倍になります。範囲外でも通常どおり釣れます。
- **釣り視点**：停船中の「釣りをする」で船上の一人称視点に切り替わります。
  キャスト前はドラッグまたは矢印キーで見渡せます。
- **キャスト**：「キャスト準備」で視点を固定。湖の画面をドラッグし、左右で方向、ドラッグの長さで飛距離を調整して、離すと投げます。水面のリングと距離表示が着水予測です。岸への投射は制限します。
- **ルアー選択**：キャスト準備前に画面下部のミノー・クランクベイト・ワーム・スピナーベイトから選択。4種類とも初めから使用でき、魚種の出やすさとアタリの頻度が少し変わります。準備開始から釣果画面・失敗後の復帰までは変更できません。
- **ルアー操作**：着水後、画面の長押しで巻き取り、短いフリックでアクション。離して待つこともできます。
- **アワセ**：光と音でアタリを通知します。押している場合はいったん離し、約1秒以内に画面をタップしてください。
- **ファイト**：長押しで引き寄せ、離してテンションを下げます。高すぎるとライン切れ、低すぎる状態が続くと逃走することがあります。
- **釣果**：近づくと自動で釣り上げ、捕獲した魚種の名前・2D画像・体長・重量を表示。「釣りを続ける」で再挑戦できます。
- **戻る・キャンセル**：キャスト前は「操船に戻る」またはEsc。準備中のEscは準備解除。キャスト後から釣果画面までは操船に戻れません。失敗後は自動でキャスト前に戻ります。

PCはマウス1つ、スマートフォンは指1本で釣りを完結できます。縦画面・横画面に対応します。
入力キャンセル・フォーカス喪失・画面非表示で長押しを解除し、キャスト準備中なら視線調整に戻ります。タブ非表示・ウィンドウ非アクティブ中はゲームを停止します。

## 構成

| ディレクトリ | 担当 |
| --- | --- |
| `src/world/` | 湖・地形・森林・山・空・水面、マップ設定 |
| `src/game/` | 船・釣りの状態遷移、確率・難易度設定、釣果データ |
| `src/input/` | Pointer Events・キーボード入力、釣りジェスチャーのマッピング |
| `src/rendering/` | 船モデル、カメラ、ルアー・ライン・水面エフェクト |
| `src/ui/` | HTML UIの状態とレスポンシブCSS |
| `tests/` | ロジック・ブラウザ操作テスト |

地形や船は生成関数を境界としているため、ゲーム状態を維持したままモデル・素材を差し替えられます。

## 現在の範囲

プロシージャルな自然景観と簡易ボートのプロトタイプです。
水面は軽量な波・反射風のシェーダー表現で、物理的な反射や高度な浮力計算は行いません。
描画負荷を抑えるため、森林はインスタンス描画、ピクセル比には上限を設定しています。
Phase 2の釣りを維持し、Phase 3A-2で12魚種の抽選・4ルアー・魚種別ファイトに拡張しています。魚の3Dモデルは使用せず、釣果のSVGはこのプロジェクト用に作成した仮画像です。効果音はWeb Audioで生成します。ブラウザの音声制限・非対応時も視覚通知で遊べます。

`src/game/fishing-config.js` で飛距離、巻き取り速度、アタリ確率、アワセ猶予、テンション難易度を調整できます。アタリは待機3秒＋平均12秒の指数分布（ルアー補正込みで平均約14〜17秒、毎回10〜20秒に収まる保証はありません）。短いフリックは一時的にヒット率を上げます。通常ファイトはテンションを調節しながら約5〜15秒が目安です。魚種と体長によって引きが変わり、大型魚はやや長くなります。抽選・ファイトの調整箇所は [釣りバランス](docs/FISHING_BALANCE.md) を参照してください。

釣果はスキーマバージョン、個体ID、魚種ID、体長cm、重量kg、捕獲日時、処理状態を持ち、セッション内で保持します。**再読み込みすると失われます**。永続保存・売却・保管・図鑑・装備強化・実績は後続Phaseで実装します。

自動テストではPCのマウス、Chromiumのタッチエミュレーション、縦横レイアウトを検証します。実機での操作感・効果音の聴感・Safariの確認と性能調整は引き続き必要です。


## Phase 3A-1・3A-2：魚種とルアー

`src/game/fish-species.js` に12魚種の通常魚データと2D画像参照を集約しています。
`getFishSpecies(id)` で取得でき、ブラックバスの従来ID・表示名・重量・抵抗値は維持しています。
12種すべてを釣り上げられ、釣果には実際に抽選された魚種IDを保存します。図鑑・売却などのUIは未実装です。
単位・計算式・暫定値・素材については [魚種データの説明](docs/FISH_SPECIES.md) を参照してください。

## Phase 3A-3a：推奨釣りポイント

北の沖・西の静水域・東の沖合の3地点に、中心と有効範囲の水面リングを追加しています。
判定は船のXZ座標を使い、ルアーの着水位置には依存しません。ルアー倍率と掛け合わせ、ポイント同士の重複は加算・乗算しません。
位置・半径・倍率の調整箇所と検証内容は [釣りポイント](docs/FISHING_SPOTS.md) を参照してください。

## Phase 3A-3b：水深・時間帯

岸からの半径方向の距離を使う簡易モデルで、ルアーの現在位置の水深を推定します。巻き取りにも追随します。
活動中の経過時間で昼3分・夜3分を繰り返し、非表示・フォーカス喪失中は停止します。釣りパネルに時間帯と推定水深を表示します。
水深・昼夜・ルアーの適性は魚種の抽選比率に反映し、アタリ発生率・ポイント倍率・ファイト難易度は変更しません。
抽選時の条件は釣果の追加項目 `conditions` に保持します。照明・空・霧・BGMは今後のPhase 4で接続するため、現在の見た目は昼夜で変わりません。
数値・計算式・検証内容は [水深と時間帯](docs/DEPTH_AND_TIME.md) を参照してください。
