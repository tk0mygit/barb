## 隔離比較

本番編集前に4候補を実行した。12魚種 × min/mid/max長 × ロッド/リールLv1/5/10の全9組合せ × 開始距離4.5001/4.51/5.5/8/16/32/40/60m × 長押し/適応長押し/完全非巻取り/0.1秒短押し断続 × QTE無効/全成功/全失敗/交互 × 30/60/144fps。

1速度あたり41,472条件・124,416回、計497,664回。1速度の合法射程内は36,288条件、射程外stressは5,184条件。たとえばLv1の40/60mはstressへ分離した。比率と分位数の母数は同一条件をfps間で重複加算しない60fps基準条件数で、人間の成功率ではない。

乱数はFIGHTごとにseed `0x9e3779b9`、LCG `(1664525*x+1013904223) mod 2^32`。遭遇抽選は行わないdomain比較で、遭遇を通す固定回帰は別節。QTEは明示的なfactoryでflickを選択し、確定deadlineへ指定結果を投入した。適応操作は0.1秒観測、tension <0.35で押し、>0.65で離す。60fpsで作った外部入力時刻列を30/144fpsへ再生する。

実装済みfactoryの隔離コピーへ、距離の最大/最小を読む観測変数だけを追加した。物理計算・入力・時計・効果は変更していない。元factoryとの状態・イベント・入力の厳密一致を24条件×4速度で確認。fps照合は既存回帰と同じ数値許容1e-9、最大差3.56e-14未満。勝敗・予約・draw数も照合し、差異0。コピー元/計測版のSHA-256と実行環境は[JSON](docs/phase5c1r/comparison.json)に保存している。
